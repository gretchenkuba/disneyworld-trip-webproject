# Disney World Trip Planning Website

This project is a multi-page informational website designed to help users plan their visits to Walt Disney World theme parks. It provides park-specific guides, ride planning ideas, and a simple survey form for user feedback.

The website was built using HTML and CSS and demonstrates fundamental front-end web development skills, including page structure, navigation design, and form handling.

Features:
- Multi-page website with navigation across different park guides:
  - Home
  - Magic Kingdom
  - EPCOT
  - Animal Kingdom
  - Hollywood Studios
  - Products page

- Clean and structured navigation bar for easy user experience
- Styled layout using external CSS
- Interactive survey form with:
  - Text input fields
  - Email validation
  - Dropdown suggestions (datalist)
  - Text areas for user feedback
- Embedded audio feature to enhance user experience
- Image integration for visual appeal

Technologies Used:
- HTML5
- CSS3

Project Purpose:
The goal of this project was to practice building a structured multi-page website while applying core front-end development skills. It demonstrates understanding of:
- Semantic HTML structure
- Navigation between pages
- Basic form creation and validation
- External CSS styling and layout design
